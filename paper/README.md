# Paper: подача в Pattern Recognition and Image Analysis

Целевой журнал: **Pattern Recognition and Image Analysis** (PRIA, Pleiades
Publishing). Правила для авторов из РФ: статья **на русском**, формат
**.docx**, 1 колонка, Times New Roman 12 pt, **двойной интервал**, объём
до 121 800 знаков с пробелами; аббревиатуры запрещены в названии,
аннотации, ключевых словах и названиях разделов; список литературы — по
алфавиту английской транскрипции фамилии первого автора, DOI при наличии.

| Файл | Что это |

| `article_ru.docx` | **Рукопись для подачи** (сгенерирована по правилам журнала) |
