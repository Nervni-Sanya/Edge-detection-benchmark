Библиотека для выделения границ на изображениях. Содержит классические методы (Sobel, Prewitt, Canny) и **авторский метод векторного освещения**, разработанный для эффективной детекции границ на цветных изображениях.

## ✨ Особенности

-  **Цветочувствительность** – метод `vector_lighting` выявляет **изолюминантные границы** (переходы между цветами одинаковой яркости). Canny даёт на таких границах **F1 = 0.000** при любой ориентации; `vector_lighting` сохраняет ~0.99.
-  **Конкурентное качество** – средний F1 **0.788** на 6-картиночном синтетическом наборе (дефолт) и лучший **0.788** по перебору 20 736 конфигураций. На реальных фото (BSDS500) — на уровне Canny по F1 при лучшей точности из всех детекторов.
-  **Настраиваемый баланс скорость/качество** – пресеты от `VL-default` (макс. качество) до `VL-turbo` (~3× быстрее Canny). Быстрые пресеты обгоняют Sobel/Prewitt по скорости, оставаясь цветочувствительными.
-  **Научно обоснован** – параметры по умолчанию выбраны полным перебором **20 736 конфигураций**.
-  **Гибкость** – настраиваемые режимы освещения, перестановки каналов, методы слияния.

> Все числа ниже воспроизводимы скриптом `tests/testing.py`. Абсолютное время зависит от машины, поэтому скорость указана **относительно Canny**. Полный отчёт (ориентация, масштаб, реальные изображения) — в [`docs/benchmark_report_2026-06.md`](docs/benchmark_report_2026-06.md).

## 📊 Результаты бенчмарка

### Синтетический набор (F1-score, допуск 2 пикселя, 256×256)

Воспроизведение: `python tests/testing.py --baseline-only`. Sobel/Prewitt бинаризуются по 95-му перцентилю; F1 на отдельных синтетических изображениях чувствителен к этому выбору.

| Изображение | Sobel | Prewitt | Canny | **VectorLight** |
|-------------|:-----:|:-------:|:-----:|:---------------:|
| `checkerboard` | 0.000 | 0.000 | 0.945 | 0.933 |
| `concentric_circles` | 1.000 | 1.000 | 1.000 | 1.000 |
| `color_patches_equal_brightness` | 1.000 | 1.000 | 0.000 | **0.909** |
| `color_wheel` | 0.510 | 0.367 | 0.471 | **0.887** |
| `blurred_disk` | 1.000 | 1.000 | 1.000 | 1.000 |
| `gray_scale` | 1.000 | 1.000 | 1.000 | 0.000 |
| **Средний F1** | 0.752 | 0.728 | 0.736 | **0.788** |

`vector_lighting` лидирует на цветовых тестах (`color_patches`, `color_wheel`) и уступает только на чисто яркостном градиенте, для которого он не предназначен.

### Цветочувствительность (изолюминантные границы)

Полосы из цветов равной яркости, 12 ориентаций (`python tests/testing.py --orientation`):

| Метод | F1 на изолюминантных границах |
|-------|:----------------------------:|
| **VectorLight** | **~0.99** (все ориентации) |
| Canny | **0.000** (все ориентации) |

Canny не видит цветовую границу без перепада яркости. (Sobel/Prewitt набирают очки на этих синтетических полосах лишь из-за остаточной разницы яркости менее одной градации серого — см. отчёт; на реальных фото это им не помогает.)

### Ориентация / анизотропия (диагональные границы)

Становится ли граница, параллельная виртуальному лучу освещения, слепой зоной? Проверено напрямую:

- **`mode=0`** (1 луч) имеет реальную слепую зону — F1 падает до **0.232** для границ, параллельных единственному лучу (135°).
- **`mode≥1`** слепых зон **не имеет** (F1 ≥ 0.875 при любой ориентации): лучи идут перпендикулярными парами.
- **`mode=2` избыточен** — даёт **попиксельно идентичные** карты с `mode=1` (лучи ±L дают равный вклад, т.к. отклик возводится в квадрат).
- **`mode=3`** (дефолт) минимизирует анизотропию до ~±8%.

### Производительность (скорость относительно Canny)

Медиана 15 прогонов на наборе 256×256 (`--baseline-only`). Больше «×» = быстрее:

| Пресет | Конфигурация | Средний F1 | Скорость к Canny |
|--------|--------------|:----------:|:----------------:|
| `VL-turbo` | mode 1, σ=0, без перест. | 0.703 | **≈2.9×** |
| `VL-fast` | mode 1, σ=0.5, без перест. | 0.728 | **≈1.9×** |
| Sobel / Prewitt | — | 0.73–0.75 | ≈1.8× |
| Canny | — | 0.736 | 1.0× (базовый) |
| `VL-balanced` | mode 1, перест. | 0.783 | ≈0.6× |
| `VL-default` | mode 3, перест. | **0.788** | ≈0.3× |

Дефолт меняет скорость на качество (~3× медленнее Canny). Для задач с ограничением по времени `VL-fast`/`VL-turbo` не уступают классике по скорости и сохраняют цветочувствительность.

### Реальные изображения — BSDS500

Полный test-сплит BSDS500 (200 размеченных людьми фото, GT — объединение аннотаторов, допуск 0.0075×диагональ, фиксированные пороги). Воспроизведение: `python tests/testing.py --bsds /путь/к/BSDS500`:

| Метод | F1 | Precision | Recall |
|-------|:--:|:---------:|:------:|
| Canny | 0.566 | 0.482 | 0.774 |
| **VL-default** | 0.552 | **0.630** | 0.509 |
| Prewitt | 0.543 | 0.582 | 0.529 |
| Sobel | 0.541 | 0.577 | 0.530 |

На реальных фото метод конкурентоспособен с классикой и обладает **наибольшей точностью** (меньше ложных границ).

### Масштабирование (размер изображения)

Ядро `vector_lighting` масштабируется корректно, но **дефолтные `sigma` и `binary_percentile` откалиброваны под ~256 px**. На больших разрешениях F1 дефолта падает (0.95 → 0.71 от 256² к 2048²), тогда как `VL-turbo` (σ=0, порог по среднему) держит F1 ≈ 0.99. **Для изображений крупнее ~512 px используйте `sigma=0–0.5` и `binary_percentile=0.0`.** Подробности и тайминги — в отчёте.

## ⚙️ Параметры метода `vector_lighting`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|:------------:|----------|
| `mode` | `int` | `3` | Режим освещения: `0`=1 вектор, `1`=2, `2`=4, `3`=8 векторов. `mode=2` избыточен (идентичен `mode=1`); используйте `1` или `3`. |
| `sigma` | `float` | `1.0` | Гауссово сглаживание. Уменьшает шум, но может размывать тонкие границы. Для изображений > 512 px берите `0–0.5`. |
| `binary_percentile` | `float` | `0.05` | Процент пикселей для бинаризации. `0.05` = оставить 5% самых ярких. `0.0` = порог по среднему. ⚠️ На градиентах / больших изображениях используйте `0.0`. |
| `use_permutations` | `bool` | `True` | Перебирать перестановки каналов. ≈ **+10% F1** на синтетике, но ~6× медленнее. |
| `merge_method` | `str` | `'max'` | Метод слияния: `'mean'`, `'max'`, `'adaptive_mean'`, `'weighted'`. `'max'` сохраняет сильнейший отклик. |
| `threshold_method` | `str` | `'percentile'` | Метод порога: `'mean_std'`, `'median'`, `'percentile'`. |
| `threshold_factor` | `float` | `0.25` | Множитель для `'mean_std'`. Игнорируется при `'percentile'`. |
| `height_weight` | `float` | `1.0` | Вес влияния высоты (третьего канала) на отклик. |
| `clean_noise` | `bool` | `False` | Морфологическая очистка. ⚠️ Удаляет тонкие границы. **Не рекомендуется**. |
| `channel_roles` | `tuple` | `None` | Явные роли каналов `(x, y, z)`. Игнорирует `use_permutations`. |
| `binary` | `bool` | `True` | Применять бинаризацию. Если `False`, возвращает карту градиентов. |
| `return_debug` | `bool` | `False` | Вернуть dict с отладочной информацией. |

## 🎯 Рекомендации по настройке

### Для максимального качества (параметры по умолчанию)

Выбраны полным перебором **20 736 конфигураций**:

```python
from vector_lighting import vector_lighting

edges = vector_lighting(
    image,
    mode=3,                # 8 векторов освещения (мин. анизотропия)
    sigma=1.0,             # Сглаживание (для >512 px берите 0–0.5)
    binary_percentile=0.05,# Оставлять 5% пикселей (для больших — 0.0)
    use_permutations=True, # Все перестановки каналов (+~10% F1, ~6× медленнее)
    merge_method='max',
    threshold_method='percentile',
    threshold_factor=0.25,
    height_weight=1.0,
    clean_noise=False,
)
```
Средний F1 = **0.788** на синтетическом наборе.

### Для высокой скорости (быстрее Canny, с цветочувствительностью)

```python
edges = vector_lighting(
    image,
    mode=1,                 # 2 вектора (mode=2 был бы идентичен, но медленнее)
    sigma=0.5,
    use_permutations=False, # Отключить перестановки
)
```
`VL-fast` ≈ 1.9× быстрее Canny при F1 ≈ 0.73; `VL-turbo` (`mode=1, sigma=0.0, binary_percentile=0.0`) ≈ 2.9× быстрее.
